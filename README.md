# JH Racing Humanoid AI Landing Page

GitHub Pages용 정적 랜딩페이지입니다.

## Files
- `index.html` : 페이지 구조
- `style.css` : 전체 디자인 및 반응형 스타일
- `script.js` : 스크롤/마우스/메뉴 애니메이션

## GitHub Pages 배포
1. 새 GitHub Repository를 생성합니다.
2. 위 3개 파일을 저장소 Root에 업로드합니다.
3. GitHub → Settings → Pages로 이동합니다.
4. Deploy from a branch → `main` / `/root` 선택 후 저장합니다.
5. 생성된 GitHub Pages URL로 접속합니다.

## 수정 추천
- `automation@example.com` → 실제 문의 이메일로 변경
- Company 영역 → 실제 회사명 / 주요 실적 / 기술 스택 추가
- Academy 영역 → 실제 교육과정 링크 연결
- 필요 시 실제 Humanoid 이미지 또는 동영상 Hero Background 추가
